# Americ — Home 06 recreation

A static recreation of the Americ "Home 06" demo, built with Vite. It uses plain HTML, CSS and JavaScript modules, and has no runtime dependencies.

```bash
npm install
npm run dev      # http://localhost:5173  (style guide: /styleguide.html)
npm run build    # outputs to dist/
```

## Structure

```
index.html              page markup, sections in reference order
styleguide.html         live preview of tokens and components
src/styles/theme.css    design tokens (single source of truth)
src/styles/base.css     reset, element typography, layout utilities
src/styles/components.css  reusable components
src/styles/sections.css    Home 06 section layouts
src/js/main.js          sticky header, portfolio swap, counters, reveal, form
src/js/carousel.js      looping autoplay carousel (Swiper-equivalent settings)
src/js/overlays.js      side panel, mobile menu, search, video lightbox
public/img/world-map.svg   generated by tools/generate-map.cjs
docs/design-system.md   design-system reference
docs/reference-inspection.md  notes from inspecting the original page
```

The contact form validates in the browser but has no backend. Connect it to your form endpoint in `initContactForm` (`src/js/main.js`).
